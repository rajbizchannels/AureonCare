# AureonCare documentation map

One line per document. Paths are relative to this folder. The repository front door is
[`../README.md`](../README.md); the release-by-release operational checklist stays at the
root as [`../DEPLOYMENT_CHECKLIST.md`](../DEPLOYMENT_CHECKLIST.md).

## Engineering — `engineering/`

- [SETUP.md](engineering/SETUP.md) — local development: database, `.env` files, the two migration runners, first operator, troubleshooting.
- [ARCHITECTURE.md](engineering/ARCHITECTURE.md) — how the pieces fit together, including multi-tenancy (schema per tenant).
- [DEPLOYMENT.md](engineering/DEPLOYMENT.md) — on-premises, customer-cloud (Helm) and SaaS (ArgoCD) deployment models.
- [RBAC.md](engineering/RBAC.md) — what decides access (`module_permissions`, `authorize`), roles, multi-role users, language, plans and limits.
- [AUDIT_LOGGING.md](engineering/AUDIT_LOGGING.md) — the append-only audit trail, PHI-read logging, the `useAudit` hook and the audit API.
- [FEATURE_IMPLEMENTATION_STEPS.md](engineering/FEATURE_IMPLEMENTATION_STEPS.md) — worked runbook for features that need tenant tables (locations, camps, specialty packs).
- [FHIR_TRACKING.md](engineering/FHIR_TRACKING.md) — the FHIR exchange and its tracking tables.
