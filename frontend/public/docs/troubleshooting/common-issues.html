Common Issues & Solutions

Login Issues

Can't log in / Invalid credentials

Solutions:

  1. Verify email address is correct
  2. Check Caps Lock is off
  3. Click "Forgot Password" to reset
  4. Clear browser cache and cookies
  5. Try different browser
  6. Contact admin if account is blocked

Password reset email not received

  1. Check spam/junk folder
  2. Verify email address on file
  3. Wait 10 minutes and retry
  4. Contact administrator

Performance Issues

System is slow

  1. Check internet speed (minimum 5 Mbps)
  2. Close unnecessary browser tabs
  3. Clear browser cache
  4. Restart browser
  5. Check if system maintenance is scheduled

Page won't load

  1. Refresh page (F5 or Ctrl+R)
  2. Clear cache and hard refresh (Ctrl+Shift+R)
  3. Check internet connection
  4. Try incognito/private mode
  5. Try different browser

Appointment Issues

Can't create appointment

  1. Verify patient exists in system
  2. Check provider availability
  3. Ensure no scheduling conflicts
  4. Check permissions (user role)

Appointment not showing on calendar

  1. Refresh calendar view
  2. Check date/time zone settings
  3. Verify appointment was saved
  4. Check calendar filters

Prescription Issues

ePrescribe not working

  1. Verify provider has DEA number
  2. Check pharmacy is in directory
  3. Ensure patient has current address
  4. Check internet connection
  5. Contact pharmacy to verify receipt

Drug interaction alert won't clear

  1. Review interaction carefully
  2. Document reason for override
  3. Get supervising physician approval
  4. Consider alternative medication

Claims & Billing Issues

Claim won't submit

  1. Verify all required fields complete
  2. Check diagnosis codes are valid ICD-10
  3. Verify CPT codes are current
  4. Ensure patient insurance is active
  5. Review validation errors

Payment not posting

  1. Verify claim exists in system
  2. Check payment amount matches
  3. Ensure no duplicate payments
  4. Review posting errors

Telehealth Issues

Video won't connect

  1. Check camera/microphone permissions
  2. Allow access in browser settings
  3. Test with browser's built-in test
  4. Close other video applications
  5. Restart browser

Poor video/audio quality

  1. Check internet speed (need 5+ Mbps)
  2. Move closer to WiFi router
  3. Close other applications
  4. Turn off video, use audio only

Data Entry Issues

Changes not saving

  1. Check for validation errors (red text)
  2. Ensure all required fields completed
  3. Check internet connection
  4. Try saving again
  5. Copy data and refresh page

Can't find patient/record

  1. Check spelling of name
  2. Try partial name search
  3. Search by MRN or DOB
  4. Check if record was archived
  5. Verify you have permission to view

Browser Compatibility

Recommended browsers:

  • Chrome 90+ (recommended)
  • Firefox 88+
  • Safari 14+
  • Edge 90+

Not supported:

  • Internet Explorer (any version)
  • Browsers older than 2 years

Getting Help

If issue persists:

  1. Press ? key for in-app help
  2. Check documentation at /docs
  3. Contact support:
    • Email: support@aureoncare.com
    • Phone: 1-800-XXX-XXXX
    • Live chat (business hours)
  4. Submit ticket via Admin Panel

When contacting support, provide:

  • Your name and organization
  • Detailed description of issue
  • Steps to reproduce
  • Browser and version
  • Screenshots if applicable
  • Error messages (exact text)
