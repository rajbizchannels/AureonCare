Vital Signs Management

Vital signs are essential measurements that indicate the body's basic functions. AureonCare automatically tracks, trends, and alerts on abnormal values.

📝 Recording Vital Signs

Method 1: From Patient Chart

  1. Open patient chart
  2. Click Summary tab
  3. Find Vital Signs section
  4. Click + Add Vitals
  5. Enter measurements
  6. Click Save

Method 2: During Clinical Note

  1. Create new progress note
  2. In Objective section
  3. Click Add Vitals
  4. Enter values
  5. Auto-added to note and chart

📋 Vital Signs Form

Blood Pressure

  • Systolic/Diastolic: e.g., 120/80
  • Position: Sitting, Standing, Supine
  • Arm: Left or Right

Temperature

  • Value: 98.6°F or 37°C
  • Route: Oral, Axillary, Tympanic, Temporal, Rectal

Oxygen Saturation

  • SpO2: 98%
  • Oxygen Source: Room Air, 2L NC, 4L NC, etc.

Weight & Height

  • Weight: lbs or kg
  • Height: feet/inches or cm
  • BMI: Auto-calculated from height & weight

🎨 Color-Coded Alerts

  • 🔴 Red: Critical - requires immediate attention
  • 🟠 Orange: Abnormal - outside normal range
  • 🟢 Green: Normal - within range

Critical Value Examples

  • Systolic BP > 180 or < 90
  • HR > 120 or < 50
  • Temp > 103°F or < 95°F
  • SpO2 < 90%
  • RR > 30 or < 10

📈 Trending & Graphs

  1. Go to patient chart > Summary tab
  2. Click View Trends
  3. Select vital sign to trend
  4. Choose date range
  5. View line graph of values over time

Use cases:

  • Monitor BP control in hypertension
  • Track weight changes
  • Assess fever patterns
  • Evaluate medication effectiveness

🔔 Vital Sign Alerts

System automatically alerts when:

  • Value is critical (red)
  • Significant change from baseline
  • Abnormal trend detected

Alert Actions:

  • Provider notified immediately
  • Pop-up warning when entering note
  • Highlighted in patient summary
  • Added to task list for follow-up

✅ Best Practices

  • ✓ Record vitals at every visit
  • ✓ Use consistent measurement technique
  • ✓ Document position for BP
  • ✓ Repeat abnormal values to confirm
  • ✓ Note patient activity before vitals (just walked, anxious, etc.)
  • ✓ Update weight at least annually
  • ✓ Check orthostatic vitals if indicated

Common Questions

Q: Can I edit vital signs after saving?
A: Yes, if entered in error. Click edit icon, make changes, note reason for edit.

Q: How often should I record vitals?
A: At minimum, every visit. More frequently for acute illness or unstable patients.

Q: What if vital signs won't save?
A: Ensure all required fields complete. Check values are in acceptable range.
