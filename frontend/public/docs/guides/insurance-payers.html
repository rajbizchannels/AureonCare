Insurance Payers Management

The Insurance Payers module manages all insurance companies and payers that your practice bills. Maintaining accurate payer information ensures smooth claims submission and faster reimbursement.

What are Insurance Payers?

Insurance payers are the companies or organizations that pay healthcare claims on behalf of patients. They include:

  • Commercial Insurance - Private insurance companies (e.g., Blue Cross Blue Shield, UnitedHealthcare, Aetna)
  • Government Programs - Medicare, Medicaid, TRICARE, VA
  • Managed Care - HMO, PPO, EPO plans
  • Workers' Compensation - Employer-sponsored injury coverage
  • Third-Party Administrators - Companies managing self-funded plans

Accessing Insurance Payers

  1. Navigate to Revenue Cycle Management (RCM)
  2. Click the Insurance Payers tab
  3. View list of all configured payers

Adding a New Insurance Payer

Step-by-Step Instructions

  1. Go to RCM > Insurance Payers
  2. Click + Add Insurance Payer button
  3. Fill in payer information form
  4. Click Save Payer

Configuring Payer-Specific Settings

Each payer may have unique requirements. Configure these settings to ensure smooth claims processing:

Claim Submission Requirements

  • Submission Method: Electronic (EDI 837), Paper (CMS-1500), or Both
  • Required Forms: Which forms does this payer accept?
  • Attachments: Do they accept electronic attachments?
  • Timely Filing Limit: How many days to submit (e.g., 90 days, 1 year)

Prior Authorization Requirements

  • Services Requiring Auth: List of CPT codes requiring prior authorization
  • Authorization Process: Phone, online portal, fax
  • Authorization Contact: Phone number or website for obtaining auth
  • Auth Reference Number Format: Expected format for auth numbers

Accepted Codes and Fee Schedules

  • Accepted CPT Codes: Which procedure codes does this payer cover?
  • Accepted ICD-10 Codes: Are there restrictions on diagnosis codes?
  • Fee Schedule: Upload or link to payer's fee schedule
  • Contracted Rates: Your practice's contracted rates with this payer

Payment Information

  • Expected Payment Time: Average days to payment (e.g., 14-30 days)
  • Payment Method: EFT, check, ACH
  • ERA (Electronic Remittance Advice): Do they send electronic payment details?
  • Payment Portal: URL for checking payment status

Editing Insurance Payer Information

  1. Go to RCM > Insurance Payers
  2. Find the payer in the list
  3. Click on the payer name or Edit button
  4. Update information as needed
  5. Click Save Changes

Deactivating an Insurance Payer

When you no longer bill a payer, deactivate rather than delete to maintain historical records:

  1. Open the payer record
  2. Change Status to Inactive
  3. Add reason in Notes (e.g., "Contract terminated 01/2026")
  4. Click Save Changes

Note: Inactive payers won't appear in dropdown menus for new claims but existing claims remain accessible.

Searching and Filtering Payers

Use search and filter options to quickly find payers:

  • Search by Name: Type payer name in search box
  • Filter by Type: Show only Commercial, Government, HMO, etc.
  • Filter by Status: Show Active or Inactive payers
  • Sort: Sort by name, type, or number of active claims

Payer Dashboard and Analytics

View important metrics for each payer:

  • Total Claims Submitted: Lifetime and current period
  • Claims by Status: Pending, approved, denied breakdown
  • Denial Rate: Percentage of claims denied by this payer
  • Average Days to Payment: How quickly this payer pays
  • Total Revenue: Amount collected from this payer
  • Outstanding A/R: Claims pending payment

Eligibility Verification Integration

When properly configured, payers support real-time eligibility verification:

  1. Ensure Electronic Payer ID is configured
  2. When creating a claim, click Verify Eligibility
  3. System queries payer in real-time
  4. Returns:
    • Coverage status (active/inactive)
    • Deductible (met/remaining)
    • Copay amount
    • Coinsurance percentage
    • Out-of-pocket maximum
    • Coverage limitations

Best Practices

Setting Up New Payers

  • ✅ Verify Electronic Payer ID: Check with clearinghouse or payer
  • ✅ Get Complete Contact Info: Phone, website, claims address
  • ✅ Document Special Requirements: Note any unique submission rules
  • ✅ Test Electronic Submission: Submit test claim before going live
  • ✅ Set Up Contracted Rates: Enter your negotiated fee schedule

Maintaining Payer Information

  • ✅ Review Quarterly: Verify contact info and requirements are current
  • ✅ Update Fee Schedules: When contracts are renegotiated
  • ✅ Track Changes: Document updates in Notes field
  • ✅ Monitor Denial Patterns: If denials increase, review payer requirements
  • ✅ Keep Authorization Lists Current: Update services requiring prior auth

Working with Clearinghouses

If you use a clearinghouse for electronic claims:

  • ✅ Use Clearinghouse Payer IDs: They may be different from standard IDs
  • ✅ Enable Payers in Clearinghouse: Must be activated on both sides
  • ✅ Test Connections: Submit test claims to verify connectivity
  • ✅ Review Clearinghouse Reports: Check for transmission errors

Troubleshooting Common Issues

Claims Rejected - Invalid Payer ID

Problem: Claims rejected with "invalid payer ID" error

Solution:

  1. Verify Electronic Payer ID is correct
  2. Check with clearinghouse for their specific payer ID
  3. Ensure payer is enabled in clearinghouse account
  4. Test with clearinghouse support if issues persist

Eligibility Verification Not Working

Problem: Cannot verify patient eligibility

Solution:

  1. Verify Electronic Payer ID is configured
  2. Check that payer supports real-time eligibility
  3. Ensure patient insurance info is complete (member ID, group number)
  4. Try again in a few minutes (may be temporary payer system issue)

Payer Not Appearing in Dropdown

Problem: Cannot find payer when creating claim

Solution:

  1. Check if payer Status is set to "Active"
  2. Search by partial name
  3. If not found, add new payer entry

Common Questions

Q: How many insurance payers can I add?

A: Unlimited. Add all payers you bill.

Q: Can I delete an insurance payer?

A: It's not recommended. Instead, deactivate the payer to preserve historical claim data. Only delete if the payer was added by mistake and has no associated claims.

Q: What if a payer has multiple plan types?

A: You can either:

  • Create one payer entry and note plan variations in Notes field
  • Create separate entries for each plan (e.g., "BCBS PPO", "BCBS HMO")
Best practice: Use one entry per payer, multiple if submission requirements differ significantly.

Q: How do I find the Electronic Payer ID?

A: Contact:

  • Your clearinghouse (they provide payer ID lists)
  • The insurance company's provider services
  • Online payer ID directories

Q: Should I add out-of-state payers?

A: Yes, if you treat patients with out-of-state insurance. Add each state plan separately (e.g., "Blue Cross Blue Shield of California" and "Blue Cross Blue Shield of Nevada" are different entities).
