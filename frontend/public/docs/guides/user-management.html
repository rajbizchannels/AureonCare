User Management

🆕 Updated in v1.2: Enhanced with language preferences and inline forms!

Adding New Users

  1. Go to Admin Panel > Users
  2. Click + Add New User
  3. Full-screen inline form appears
  4. Fill in user details

User Information

Personal:

  • First Name, Last Name
  • Email (login username)
  • Phone Number
  • Address, Date of Birth

Professional:

  • License Number
  • NPI Number (for billing)
  • DEA Number (for prescribing)
  • Specialty, Credentials

🆕 Language Preference:

  • Select from 8 languages
  • Interface auto-switches on login
  • Supported: English, Spanish, French, German, Arabic, Hindi, Mandarin, Portuguese

Assign Roles

Select one or more roles:

  • Administrator: Full system access
  • Doctor: Clinical provider
  • Nurse: Clinical support staff
  • Receptionist: Front desk, scheduling
  • Billing Manager: Revenue cycle
  • CRM Manager: Marketing, outreach

User Status

  • Active: Can log in
  • Pending: Account created, not activated
  • Blocked: Cannot log in

Editing Users

  1. Find user in list
  2. Click user row or Edit button
  3. Full-screen inline form opens
  4. Make changes
  5. Click Save Changes

Managing Roles

  1. Open user record
  2. Go to Roles section
  3. Check/uncheck roles
  4. Click Update Roles

⚠️ Users must have at least one role.

Deactivating Users

  1. Open user record
  2. Change status to Blocked
  3. User cannot log in
  4. Historical data preserved

Password Management

Resetting passwords:

  1. Edit user
  2. Click Reset Password
  3. User receives email with reset link

Password requirements:

  • Minimum 8 characters
  • 1 uppercase, 1 lowercase
  • 1 number, 1 special character

User Permissions

🆕 Expanded in v1.2: Granular permissions for all 14 modules

Each role can have permissions for:

  • View, Create, Edit, Delete

Across modules:

  • Patients, Appointments, Providers
  • EHR, Prescriptions, Diagnoses
  • Lab Orders, Telehealth, RCM
  • Pharmacy, Offerings, CRM
  • Administration, Reports

Best Practices

  • ✓ Use principle of least privilege
  • ✓ Review user access quarterly
  • ✓ Deactivate terminated employees immediately
  • ✓ Use strong password policy
  • ✓ Monitor failed login attempts
  • ✓ Document access changes
