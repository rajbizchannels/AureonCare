Practice Settings

Configure clinic information, hours, and operational settings.

Organization Information

  1. Go to Admin Panel > Organization Settings
  2. Update clinic details

Fields:

  • Organization Name
  • Address (street, city, state, ZIP)
  • Phone Number
  • Email
  • Website
  • Tax ID (EIN)
  • NPI Number (for billing)
  • Logo (upload image)

Working Hours

Set hours for each day of week:

DayOpenClose
Monday8:00 AM5:00 PM
Tuesday8:00 AM5:00 PM
.........

Options:

  • Mark as closed (weekends)
  • Set break times
  • Add multiple shifts

Appointment Settings

  • Default Duration: 15, 30, 45, or 60 minutes
  • Booking Window: How far in advance (e.g., 90 days)
  • Same-Day Booking: Allow/disallow
  • Cancellation Policy: Hours notice required
  • No-Show Policy: Fee amount

Reminder Settings

  • Email reminders (24 hours before)
  • SMS reminders (2 hours before)
  • Patient portal notifications

Billing Settings

  • Payment Methods: Cash, check, card, ACH
  • Payment Gateway: Stripe, Square integration
  • Invoice Template: Upload custom template
  • Late Fees: Percentage or fixed amount
  • Payment Terms: Net 30, Net 15, etc.

Communication Settings

Email Configuration

  • SMTP server settings
  • From email address
  • Email templates

SMS Provider

  • Select provider (Twilio, etc.)
  • Configure API credentials
  • From phone number

Patient Portal

  • Enable/disable portal
  • Self-registration settings
  • Portal features toggles

Security Settings

  • Session Timeout: Minutes of inactivity
  • Password Policy: Complexity requirements
  • Two-Factor Auth: Enable/disable
  • IP Restrictions: Whitelist IPs
  • Audit Logging: Track all access

Integration Settings

  • Lab Integration: HL7 connection
  • Pharmacy (NCPDP): ePrescribe setup
  • Payer Connectivity: Clearinghouse
  • FHIR API: Enable interoperability

Backup Settings

🆕 Updated in v1.2: Cloud backup with OAuth!

  • Automatic Backups: Daily at 2 AM
  • Google Drive: OAuth integration
  • OneDrive: OAuth integration
  • Local Backup: On-premises storage
  • Retention: 30 daily, 12 weekly, 12 monthly

Best Practices

  • ✓ Review settings quarterly
  • ✓ Test backup restoration
  • ✓ Keep contact info current
  • ✓ Update hours for holidays
  • ✓ Document settings changes
