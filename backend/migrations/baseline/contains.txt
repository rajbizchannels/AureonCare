# The baseline is a pg_dump snapshot taken partway through the numbered series. Replaying
# the files below on top of it is not merely redundant, it is destructive: several of them
# (001_update_users_table, 014_create_rbac_and_plans, 024_create_appointments_table,
# 025_merge_providers_id_with_user_id) begin with DROP TABLE ... CASCADE and rebuild the
# table in its old integer-keyed shape, discarding everything the snapshot holds. Others
# re-add triggers and indexes that already exist, or alter columns that have since been
# rewritten. That is why the historical chain cannot simply be replayed from empty.
#

# baseline already contains. A migration is listed here only if the baseline holds its
# result. Files NOT listed -- including every future migration -- always run.

# existing database `--adopt` records every file, so this list is not consulted there.
