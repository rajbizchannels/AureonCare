Locations

Found under Settings → Practice → Locations.

Until V1.5 AureonCare assumed one implicit place. Locations makes sites explicit, which is what multi-branch practices, departments, and anything held off-site need.

Location Types

TypeUse For
ClinicA permanent site your practice operates
CampA venue used for an outreach event
MobileA vehicle or travelling service
PartnerA site operated by someone else where you deliver care

Adding a Location

  1. Go to Settings → Practice → Locations
  2. Click + New Location
  3. Enter the details
  4. Click Save
FieldDescription
NameWhat the site is called
TypeClinic, Camp, Mobile or Partner
AddressStreet address
CityCity or town
PhoneSite contact number
Time ZoneThe site's local time zone
Primary SiteWhether this is the practice's main site

Exactly one location is primary. Marking a different site primary moves the flag rather than creating a second one. Your existing clinic details became the primary site automatically when you upgraded.

What Carries a Location

Once sites exist, these records can each name one:

  • Appointments — where the appointment takes place
  • Provider availability — which site a clinician works from, and when
  • Working hours — opening hours per site
  • Inventory stock movements — which site stock moved at

A record without a location is still valid; the field is optional everywhere.

Removing a Location

  1. Open the location
  2. Click Delete
  3. Confirm

Deleting a site never deletes history. Appointments, stock movements and availability that referenced it simply lose the location reference; the records themselves stay intact.

Best Practices

  • ✓ Create a location before scheduling anything at it
  • ✓ Set the time zone correctly — appointment times depend on it
  • ✓ Use Camp type for outreach venues rather than a permanent clinic
  • ✓ Keep the primary site pointing at your main place of business
  • ✗ Don't delete a site to "clean up" — mark it inactive if it may return
