Clinical Notes & Medical Documentation

Clinical notes are the foundation of patient care documentation. AureonCare provides comprehensive tools for creating, managing, and maintaining accurate clinical records using SOAP notes, templates, and voice dictation.

📊 Accessing Patient Charts

  1. Use Ctrl+K for universal search
  2. Type patient name or MRN
  3. Click patient from results
  4. Patient chart opens with Summary tab

Chart Sections

Summary Tab

  • Vital Signs: Latest BP, HR, temp, SpO2, weight, BMI
  • Active Problems: Current diagnoses
  • Medications: Active prescriptions
  • Allergies: Drug/food allergies with reactions
  • Recent Visits: Last 5 encounters
  • Upcoming Appointments
  • Active Lab Orders
  • Care Team

Progress Notes Tab

All clinical documentation including:

  • Office visit notes
  • Telehealth encounters
  • Phone consultations
  • Procedure notes
  • Hospital consultations

SOAP Note Structure

S - Subjective

Patient-reported symptoms

  • Chief Complaint: Why patient came ("chest pain x 2 days")
  • HPI: Onset, location, duration, character, severity (1-10)
  • Review of Systems: 14-system checklist
  • PMH/PSH/FH/SH: Relevant history

O - Objective

Measurable findings

  • Vital Signs: BP 120/80, HR 72, Temp 98.6°F, RR 16, SpO2 98%
  • Physical Exam: By body system (General, HEENT, CV, Resp, Abd, etc.)
  • Test Results: Labs, imaging, point-of-care testing

A - Assessment

Clinical impression

  • List diagnoses with ICD-10 codes
  • Status: New, Stable, Worsening, Resolved
  • Mark primary diagnosis for visit

P - Plan

Treatment and follow-up

  • Medications: New Rx, changes, discontinuations
  • Orders: Labs, imaging, procedures
  • Referrals: Specialist consultations
  • Education: Patient counseling provided
  • Follow-up: When to return (RTC 2 weeks)
  • Precautions: When to seek urgent care

🛠️ Documentation Tools

Templates

  1. Click Templates button
  2. Browse by specialty or type
  3. Select template
  4. Sections auto-populate
  5. Customize for patient

Macros/SmartPhrases

Type shortcuts that expand to full text:

  • .ros → Full Review of Systems
  • .pe → Physical Exam template
  • .dm → Diabetes management plan
  • .htn → Hypertension management

Voice Dictation

  1. Click microphone icon
  2. Speak clearly
  3. Real-time transcription
  4. Medical terms recognized
  5. Review and edit

Copy Forward

Bring forward from previous visit:

  • Past Medical History
  • Current Medications
  • Allergies
  • Social History

📋 Completing Notes

Review Checklist

  • ✓ All sections complete
  • ✓ Diagnoses coded correctly
  • ✓ All orders placed
  • ✓ Follow-up plan documented
  • ✓ Time documented (for billing)

Sign and Lock

  1. Click Sign Note
  2. Apply e-signature
  3. Note becomes legal record
  4. Cannot edit (only addendum)

⚠️ Important: Sign notes same day as visit. Unsigned notes affect billing and compliance.

Addendums

For signed notes needing changes:

  1. Open signed note
  2. Click Add Addendum
  3. Enter additional information
  4. Cannot modify original text
  5. Addendum timestamped separately

✅ Best Practices

  • ✓ Sign notes same day
  • ✓ Use specific, objective language
  • ✓ Document patient education
  • ✓ Link diagnoses to orders
  • ✓ Include time spent
  • ✓ Update problem list
  • ✓ Document med reconciliation

❌ Avoid

  • ✗ Copy-paste without review
  • ✗ Non-standard abbreviations
  • ✗ Leaving notes unsigned
  • ✗ Modifying signed notes
  • ✗ Vague documentation

Common Questions

Q: Can I edit a signed note?
A: No. Use addendum feature instead.

Q: How long to sign notes?
A: Within 24-48 hours of encounter.

Q: What if I make a mistake?
A: If unsigned, edit. If signed, add addendum.
