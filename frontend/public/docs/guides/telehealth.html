Telehealth Video Consultations

Telehealth enables virtual patient visits through secure video conferencing, expanding access to care and improving convenience.

📅 Scheduling Telehealth Appointments

  1. Go to Practice Management module
  2. Click + New Appointment
  3. Select patient
  4. Choose provider
  5. Set appointment type: Telehealth
  6. Select date and time
  7. Add reason for visit
  8. Click Save

✉️ Patient receives email/SMS with video link 30 minutes before appointment.

🎥 Starting a Telehealth Session (Provider)

  1. Go to Appointments on dashboard
  2. Find telehealth appointment
  3. Click Start Video Call button
  4. Allow camera and microphone access
  5. Wait for patient to join

Before Session Checklist

  • ✓ Test camera and microphone
  • ✓ Ensure good lighting
  • ✓ Check internet connection (minimum 5 Mbps)
  • ✓ Find quiet, private location
  • ✓ Have patient chart open

👤 Patient Joining Session

Patients can join via:

  • Email link: Click link in appointment reminder
  • Patient Portal: Log in > Appointments > Join Video
  • SMS link: Tap link on mobile device

Patient preparation:

  • Test device camera/mic
  • Join 5 minutes early
  • Have pharmacy info ready
  • List current medications

🛠️ During the Video Consultation

Video Controls

Button Function
🎤 MuteToggle microphone on/off
📹 VideoToggle camera on/off
💬 ChatSend text messages
📺 Screen ShareShare screen for education
📝 NotesOpen clinical note
📞 End CallDisconnect session

Clinical Documentation Tools

  • Split Screen: View patient video + EHR simultaneously
  • Quick Note: Document while on video
  • ePrescribe: Send prescriptions during call
  • Lab Orders: Order tests immediately
  • Upload Photos: Patient can share images

Patient Interaction

  • Maintain eye contact (look at camera)
  • Speak clearly and at normal pace
  • Ask patient to show relevant areas (rash, wound, etc.)
  • Use visual aids via screen share
  • Confirm patient understanding

📋 Post-Session Documentation

Clinical Note Requirements

  • Note Type: Telehealth
  • Document:
    • Location (patient state/location)
    • Consent obtained for telehealth
    • Video quality assessment
    • Limitations (if unable to examine)
  • Include: "Patient seen via secure video consultation"

Example Documentation

"Patient seen via secure HIPAA-compliant video telehealth from patient's home in California. Verbal consent obtained. Video and audio quality good. Full history obtained. Visual examination performed as appropriate for virtual visit."

💳 Billing for Telehealth

CPT Codes

Code Description
99202-99205New patient telehealth (15-60 min)
99212-99215Established patient telehealth (10-40 min)
Modifier 95Required for telehealth billing

Requirements:

  • Document total time spent
  • Include telehealth-specific language
  • Add Modifier 95 to claim
  • Note patient location (state)

🔒 Privacy & Security

  • HIPAA-Compliant: End-to-end encryption
  • BAA in Place: Business Associate Agreement with video vendor
  • No Recording: Unless patient consents (document in chart)
  • Private Location: Ensure no unauthorized listeners
  • Screen Sharing: Only share relevant, de-identified info

🔧 Troubleshooting

Common Issues

Problem Solution
No videoCheck camera permissions in browser settings
No audioCheck microphone permissions, test speakers
Poor qualityClose other programs, check internet speed
Can't connectRefresh page, try different browser
Dropped callReconnect using same link

Browser Requirements

  • Recommended: Chrome, Firefox, Safari (latest versions)
  • Mobile: iOS 12+, Android 8+
  • Bandwidth: Minimum 5 Mbps up/down

✅ Best Practices

  • ✓ Test equipment before first appointment
  • ✓ Start session 5 minutes early
  • ✓ Have backup phone number for patient
  • ✓ Document technical issues in note
  • ✓ Set expectations with patient beforehand
  • ✓ Follow up with in-person visit if needed
  • ✓ Send visit summary to patient after

🚫 When NOT to Use Telehealth

  • Emergency situations (chest pain, stroke symptoms)
  • Requires physical examination
  • Complex procedures
  • Patient preference for in-person
  • Poor internet connectivity
