Most practice software has a dashboard nobody looks at. It is the screen you pass through on the way to the screen you wanted, full of numbers that were true at some point last week.

That happens for a specific reason: the dashboard was built as a report. Reports are things you run, and a thing you have to run is a thing you stop running.

AureonCare's dashboard is built the other way round — as the place the day starts and as a launchpad into the work. This issue is the one-minute version of how to read it.

```
Four numbers, counted live

Home ▸ Dashboard is the practice at a glance. Four tiles, each counting something that is true right now.

Today's appointments — what the day actually holds, not what was booked at close of business yesterday.

Active patients — the size of the register you are working with.

Open tasks — what has been handed to someone and not yet finished.

Revenue this month — the money side, in the same view as the clinical side, without opening a separate reporting tool.

Between them those four answer the question a practice manager asks at 8am: is today normal, and if not, where is it not normal.
```

**→ Insert `assets/v04/03-not-a-report.png` here.**

```
Not a report you run

This is the distinction worth internalising, because it changes the habit.

These tiles are not a report. There is nothing to generate, no date range to pick, no schedule to set up. They are the current state of the practice, and they move as the day does. Someone books an appointment at 10:15 and the number changes.

That matters because of what it costs you to look. A report has a price — you have to decide to run it, wait for it, and interpret it against whenever it was last run. A live tile costs nothing but a glance. So you glance, and glancing several times a day is what turns a dashboard from decoration into an instrument.

It is also why the dashboard is a reasonable thing to leave open on a second screen at the front desk, which a report never is.
```

**→ Insert `assets/v04/04-launchpad.png` here.**

```
Every card opens the module behind it

A number on its own does not help anyone. What helps is getting from the number to the work in one movement.

Every card on the dashboard is clickable, and clicking it opens the module behind it. Open tasks takes you to the tasks. Today's appointments takes you to the day. You land in the module itself, ready to work rather than to read — no going back to the rail, no navigating, no remembering which workspace it lived under.

Quick Actions does the same thing from the other direction. Instead of clicking a number that already exists, you start something new: a patient, an appointment, a claim — without hunting for the module first.

So the habit is a short one. Read the tiles at the start of the day. Then click the one that needs you.
```
