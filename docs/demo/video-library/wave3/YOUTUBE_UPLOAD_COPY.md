# Wave 3 — YouTube upload copy

Paste-ready text for each video, split by the field it goes into in YouTube
Studio. Everything in a fenced block is **copy verbatim** — no editing, no
internal notes mixed in.

The per-video `.metadata.md` files are the production record and contain notes
that must *not* be published (which `.srt` to attach, which narration engine
rendered the track). This file is the publishing view: only what a viewer
should see.

Wave 3 assumes Wave 1. These videos say "go to Insights, then Reports" without
stopping to explain the navigation, because
[Wave 1](../wave1/YOUTUBE_UPLOAD_COPY.md) already did.

Chapters and timestamps match the `en-US-Neural2-D` renders in this folder.
Re-record and they move by a second or two — check them against the finished
files before pasting.

## Before publishing

YouTube silently drops a chapter list if the first entry is not `00:00` or if
any entry runs past the end of the video. The lists above are copied from the
`.chapters.txt` files the recorder wrote, so they match these renders — but
scrub each video once against its list before saving the description.
